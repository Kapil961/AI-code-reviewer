## 🚀 Project Overview

AI Code Reviewer is an automated repository analysis tool.

Users can upload a Python project as a ZIP file. The system extracts the repository, analyzes Python source files, detects potential issues, and generates an AI-powered code review report.

---

## ✨ Features

### 📂 Repository Analysis
- Upload complete Python projects as ZIP files
- Automatically extract repository contents
- Detect Python source files

### 🔍 AST Based Code Analysis
- Parse Python files using Abstract Syntax Tree (AST)
- Extract:
  - Functions
  - Classes
  - Imports
  - Async functions
  - Methods

### 🛠 Static Code Analysis
Detects:
- Missing docstrings
- Code quality issues
- Maintainability problems

### 🧠 AI Code Review
Using Gemini AI:
- Generates overall code score
- Identifies strengths and weaknesses
- Provides improvement suggestions
- Gives security recommendations
